Pasteup 便携版使用说明（Windows x64）
=====================================

Pasteup 是一个常驻托盘的剪贴板历史 / 截图贴图小工具。


一、启动
  1. 将压缩包完整解压到任意文件夹（例如 D:\Tools\Pasteup）。
     注意：必须保留文件夹内所有文件，不能只拷走 Pasteup.exe。
  2. 双击 Pasteup.exe 启动。首次启动可能稍慢（系统扫描约 140MB 文件），属正常现象。
  3. 程序没有主窗口，启动后驻留在屏幕右下角「通知区域」（托盘，时钟旁，
     可能折叠在 ^ 隐藏区）。重复双击只会唤起已运行的实例，不会双开。
  4. 程序只从启动之后开始记录剪贴板；启动前复制的内容不会出现在历史里。

二、默认快捷键
  · Alt+V  唤起 / 收起剪贴板面板
           （↑↓ 选择、Enter 粘贴到当前窗口、Esc 隐藏、空格预览、右键更多操作）
  · Alt+S  开始截图：拖框选择区域，松开鼠标生成贴图

  托盘图标：左键单击 = 唤起面板；
            右键菜单 = 唤起面板 / 截图 / 贴图列表 / 设置 / 退出。
            「贴图列表」= 当前屏幕上的贴图窗口（Alt+S 截图生成）：展开后逐张列出
            （缩略图 + 原图尺寸），点击即把它激活到最前；菜单底部「全部关闭」
            一次收掉所有贴图。

三、设置与退出
  · 设置：托盘右键 →「设置」；也可以点面板右上角的齿轮图标。
    设置里可改：主题、快捷键（热键）、选中即粘贴、唤起时回到顶部、面板锚点、
    贴图透明度与缩放、历史容量与保留天数、退出时清空历史等；
    「关于」页还可查看版本号、打开数据目录、清空历史。
  · 隐藏面板：按 Esc 或点击面板以外区域，面板会收起（不是退出）。
  · 退出：托盘右键 →「退出」（这是正常的退出方式）。
    面板按 Alt+F4 只是关闭面板窗口，程序仍驻留在托盘，下次按热键会重新打开；
    设置窗口点 × 也是收回托盘。

四、首次运行提示（重要）
  · 本程序未做数字签名。若 Windows 弹出「Windows 已保护你的电脑」
    （SmartScreen 提示），点「更多信息」→「仍要运行」即可。
  · 个别安全软件可能对未签名的程序误报，如被拦截请添加信任。
  · 本程序为 x64 自包含版本：不需要另外安装 .NET 运行时，也不需要管理员权限。

五、数据与隐私
  · 历史记录、设置、图片缓存和日志保存在：%LOCALAPPDATA%\Pasteup
    （在资源管理器地址栏输入 %LOCALAPPDATA% 回车，即可看到 Pasteup 文件夹）
  · 历史按 Windows 用户账户隔离，只保存在本机，不会上传网络。
  · 便携的只是程序本身：历史数据固定在上述系统目录，不随程序文件夹移动。
  · 升级：先托盘右键退出，再解压新版本覆盖到原文件夹
    （程序运行中文件被占用，无法直接覆盖）；历史记录不会丢失。
  · 卸载：托盘右键退出 → 删除程序文件夹；
    若要同时清空历史，再删除 %LOCALAPPDATA%\Pasteup 文件夹。
  · 程序不安装系统服务；「设置 → 通用 → 开机自启」可开关开机自启
    （默认关闭，只写当前用户启动项，不需要管理员权限）。

六、系统要求
  · Windows 11 或 Windows 10（建议 22H2 及以上），64 位（x64）；界面为中文。
  · 已在 Windows 11 实机验证；Windows 10 与 ARM64 设备未实测
    （ARM64 设备依赖系统 x64 兼容层运行）。
  · 需要正常的 Windows 桌面会话（资源管理器/explorer.exe 运行、有通知区域；
    服务器核心版 Server Core 不适用）。

七、常见问题
  1. 按 Alt+V 没反应？
     可能快捷键已被其他软件占用（启动时会弹窗提示注册失败）。
     可在「设置 → 热键」页中改成其他组合，或关闭占用该快捷键的软件。
     在设置里按下被占用的组合会没有反应（仍冲突），换一个组合即可。
  2. 找不到托盘图标？
     点任务栏右下角的 ^ 展开隐藏图标；若仍没有，检查是否被安全软件拦截。
  3. 想开机自动启动？
     打开「设置 → 通用 → 开机自启」开关即可（默认关闭）。只写当前用户
     启动项、不需要管理员权限；关掉开关立即移除本程序的启动项。若之后移动了
     程序文件夹，下次启动会自动把自启指向更新为新位置。
  4. 粘贴到某些窗口没反应？
     以管理员权限运行的窗口会拒绝普通程序的模拟按键（Windows UIPI 安全机制）。
     需要时右键「以管理员身份运行」本程序（会弹 UAC），或在普通窗口中使用。
  5. 出问题需要反馈？
     日志位于 %LOCALAPPDATA%\Pasteup\logs，可把该文件夹打包发给作者。
